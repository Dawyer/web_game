# Plants vs Zombies：非官方粉丝塔防实现

本游戏整理自 MIT 开源项目 plantsvszombiesjs/plantsvszombiesjs.github.io。游戏使用 Unicode emoji、文字与 CSS，保留上游英文界面和玩法，不包含原版素材。上游固定版本与改动见 ATTRIBUTION.md，完整 MIT 条款见 LICENSE。

## 运行方法

在仓库根目录执行（需要 Python 3）：

    python3 -m http.server 8000 --bind 127.0.0.1

打开 http://127.0.0.1:8000/ 查看列表，或直接打开 http://127.0.0.1:8000/plants-vs-zombies/ 。也可在本游戏文件夹内运行相同命令，然后访问 http://127.0.0.1:8000/ 。终端按 Ctrl+C 停止服务。

这是单文件静态游戏，无需编译、npm 或第三方运行依赖。页面内的 CSS 和 JavaScript 均为内联代码，没有 http(s) 外链、内嵌图片或另行分发的图片、声音、字体。emoji 的外观取决于本机字体。

## 玩法与操作

- 页面加载即开局，初始拥有 200 阳光，草坪为 5 行、9 列。
- 点击或触摸植物卡片，再点击或触摸空格种植，消耗卡片上标示的阳光；每种一次需重新选择卡片。
- 点击或触摸飘落的太阳、向日葵产生的太阳以收集阳光。向日葵用于生产阳光，攻击植物自动攻击，防御植物用于阻挡。
- 僵尸从右向左移动，阻止它们穿过防线，目标是抵挡全部 20 波。
- Pause 暂停，Resume 继续；Restart / Play Again 重开。
- 速度按钮循环切换 x1 / x2 / x3；Top 10 查看当前浏览器的排行榜；Full 切换全屏，是否可用取决于浏览器权限。
- D 键切换调试信息；主要操作为鼠标或触屏，不提供完整键盘操作。
- 手机建议横屏：上游在宽度不超过 768px 的竖屏显示 Rotate Your Device 提示，本仓库未改动此行为。

## 本地存储与验证边界

游戏通过当前站点的 localStorage 保存排行榜、部分状态和全屏标志。源码虽写入 pvz_gameState，但 loadGameState() 未据此恢复对局；刷新会重新开局，不应视作支持断点续玩。切换浏览器、端口或清理站点数据会影响存储。

美术已由 emoji 替换为 `art/` 下的原创精灵图（9 种植物、5 种僵尸、阳光、豌豆、草坪背景），
渲染层用 CSS `background-image` 实现，玩法逻辑未改动。

验收记录（2026-11-12，由协调方在本机独立执行）：克隆仓库 → `python3 -m http.server` → 无头 Chrome 加载
并读取 DOM/控制台 → CDP 真实点击交互。结果：列表页与游戏页均返回 200；加载与交互全过程无 JavaScript
报错；种植向日葵/豌豆射手/坚果墙成功并正确扣减阳光；阳光采集生效（0 → 50）；僵尸按行进场、波次推进
（1 → 2）、分数增长；暂停/继续与 Top 10 面板正常；精灵图与草坪背景全部加载（无 404）；375px 窄屏显示
上游自带的横屏提示。尚未覆盖：完整 20 波通关流程、真机触屏、排行榜写入（需打完一局触发）。
