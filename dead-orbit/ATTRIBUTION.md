# 原创与授权说明 · 静默轨道 DEAD ORBIT

## 代码

本项目所有 JavaScript、CSS、HTML 均为本项目原创实现，不沿用任何现有游戏的名称、代码、美术或文字。采用 MIT 许可证，见 [LICENSE](./LICENSE)。

## 美术

`art/scene.svg`、`art/favicon.svg` 均为本项目原创 SVG 矢量绘制：冷白灰舱体、舷窗星海、橙色警报灯、储物柜、导航终端、生命维持面板、逃生舱门、座椅、控制台、工具箱等场景元素，以及热点高亮、星图叠加、信标星标注等界面元素。全部为矢量，任意缩放清晰，无位图、无内嵌 base64、无外链。

## 音效

所有音效由 `src/audio.mjs` 通过 Web Audio API 现场合成（振荡器 + 包络 + 滤波白噪），不落任何音频文件，因此不存在音频素材许可问题。声音只做氛围与反馈，不承载解谜信息，听障玩家可完整通关。

## 字体与外部资源

不加载任何外部字体、CDN、图片或音频。页面只请求本目录内的 `style.css`、`src/*.mjs`、`art/*.svg`。无 http(s) 外链、无内嵌图片、无数据上传、无账号、无联网排行、无付费、无广告、无 SDK 占位。
