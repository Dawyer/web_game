## 0. 一句话设定

深空监测站「渡鸦-7」失联 11 个月。你在逃生舱座椅上醒来，六名船员不见踪影，广播循环着轨道衰减警报。发射控制台需要三组授权码。所有人都消失了，只有一扇门为你而锁。

## 1. 剧情定稿（逐字锁定）

### 1.1 冷开场（首次进入显示一次）

> 你在逃生舱座椅上醒来，后脑一阵钝痛。广播循环着同一句话：「轨道衰减，脱离窗口关闭中。」通讯全断，六名船员不见踪影。中控屏跳出一行红字：**发射码校验失败，需三组授权。**

### 1.2 三段叙事递进（线索即叙事碎片）

1. **生命体征**：面板显示六名船员全部处于休眠状态，不是撤离。最后一人（林澈）的曲线显示他在清醒状态下被主动关入休眠。悬念：谁关的，为什么。
2. **星图定位**：导航终端显示渡鸦-7 已偏离轨道，正以 0.3 AU/日 接近最近恒星。倒计时不是吓唬人，是真的。
3. **电路重接**：保险丝复位、供电恢复的瞬间，一段被切断的录音自动播放 —— 揭示真相。

### 1.3 船长录音（供电恢复时自动播放，逐字锁定）

> 「如果你听到这段录音，说明你还活着，而且还没被感染。我把他们送进休眠，切断了通讯，把渡鸦-7 导向恒星。跟着信号上船的那个东西，烧掉它，才能彻底干净。你是唯一没被它碰过的 —— 事发前你就在休眠里。锁住你的安全协议是我下的最后一道命令：别出去，等我安排好逃生舱。输入三组授权，门会开。对不起。」

**反转内核**：锁住你的不是敌人，是救你的人。船长是幕后英雄，不是反派。

### 1.4 结局（输入正确授权码后，逐字锁定）

> 授权通过。舱门弹开。渡鸦-7 在身后烧成一道光。
> 屏幕最后一行字，是林澈留给你的私人留言：「小满，替我看看那边的天。」

船员名单（储物柜内）：林澈（船长）、周岚、陈默、苏叶、何舟、你（小满）。最后一条日志停在 11 个月前：「例行值守，一切正常。」

## 2. 场景与热点（单一舱室，固定视角）

| 热点 id | 名称 | 作用 |
|---|---|---|
| `locker` | 储物柜 | 藏应急电池 + 船员名单 |
| `seat` | 座椅 | 下方检修格藏星图仪 |
| `toolbox` | 工具箱 | 藏保险丝 + 维护日志（读取顺序规则） |
| `nav` | 导航终端 | 装电池后开机，显示坐标提示与轨道衰减警告 |
| `porthole` | 舷窗 | 用星图仪后显示三颗信标星及数字 |
| `lifesupport` | 生命维持面板 | 换保险丝后亮起，显示生维读数 + 船员体征 + 触发录音 |
| `console` | 发射控制台 | 三组授权输入 + 校验位公式屏保 |
| `door` | 逃生舱门 | 授权通过后弹开（结局动画） |

舱体视觉：冷白灰金属面板 + 舷窗星海 + 橙色警报灯（低频闪烁）+ 警示条纹 + 管线细节。SVG 矢量绘制，零外链、零内嵌位图。

## 3. 道具（3 件，各有唯一用途，无摆设）

| 道具 id | 名称 | 取得位置 | 唯一用途 |
|---|---|---|---|
| `battery` | 应急电池 | 储物柜 `locker` | 给导航终端 `nav` 供电 |
| `starchart` | 星图仪 | 座椅 `seat` | 在舷窗 `porthole` 定位信标星 |
| `fuse` | 保险丝 | 工具箱 `toolbox` | 修复生命维持面板 `lifesupport` |

有效组合只有三组：`battery→nav`、`starchart→porthole`、`fuse→lifesupport`。其他组合一律提示「这里用不上」，不消耗道具、不惩罚。道具取得后保留在物品栏，不会丢失。

## 4. 线索与授权码推导（唯一解，无猜测）

**授权码 = `418250`**，六位 = 三位坐标 + 两位生维 + 一位校验。控制台三组授权槽显示为 `坐标[___] 生维[__] 校验[_]`。

### D1–D3 轨道坐标 = `418`
- 导航终端（装电池后）：「轨道偏离警告。渡鸦-7 正以 0.3 AU/日 接近最近恒星。定位信标：舷窗方向。请用星图仪读取坐标。」
- 舷窗（用星图仪后）：叠加层圈出三颗信标星，按亮度标注 —— 最亮 → **4**，次亮 → **1**，最暗 → **8**。
- 工具箱维护日志写明规则：「信标星按亮度由高到低读取。」
- 结论：坐标段 **418**。

### D4–D5 生命维持 = `25`
- 生命维持面板（换保险丝后）：O₂ 浓度 **26%**，舱压 **5 kPa**。
- 面板贴纸：「取氧气十位与舱压个位。」
- 结论：氧气十位 **2**，舱压个位 **5** → 生维段 **25**。

### D6 校验位 = `0`
- 控制台屏保：「校验位 = 前五位之和的个位。」
- 4 + 1 + 8 + 2 + 5 = 20 → 个位 **0**。
- 结论：校验位 **0**。校验位是「啊哈」时刻，不单独藏数字。

### 可解性约束
- 每条线索都可读、有视觉对应物；不依赖声音、颜色或外部知识。
- 三件道具各有唯一用途，无摆设；所有线索确定可读，无随机、无猜测。
- 输错只提示「授权失败，请核对」，不锁死、不扣次数、无倒计时、无死亡。

## 5. 交互规则

- 点热点 → 查看该处描述/线索，写入「线索簿」可随时回看。
- 点物品栏道具选中 → 再点场景热点使用；再点一次道具取消选择。选中态有明确高亮。
- 控制台数字键盘：0–9、退格、清空、确认；输满六位才可确认。
- 线索簿按钮：列出所有已发现线索原文，防止玩家记不住数字（可解性关键）。
- 提示按钮：按当前进度给出三层提示，可反复点、逐层升级，不惩罚。
- 设置：静音、减弱动效、布局切换、查看统计、重置当前局。
- 键盘：数字键输入、Enter 确认、Backspace 退格、Esc 返回/取消选择、H 提示、J 线索簿、M 静音。

## 6. 提示系统（按当前进度给对应目标的三层提示）

进度阶梯：`locker → useBattery → seat → useStarchart → toolbox → useFuse → code → done`

| 目标 | 第一层（思路） | 第二层（下一步） | 第三层（完整解法） |
|---|---|---|---|
| locker | 房间左侧的储物柜好像没锁严。 | 点开储物柜，看看里面有什么。 | 点储物柜拿走应急电池，它能给导航终端供电。 |
| useBattery | 导航终端黑着屏，它在等电。 | 选中应急电池，再点导航终端。 | 点物品栏的应急电池选中，再点导航终端使用。 |
| seat | 座椅底下似乎卡着什么东西。 | 点座椅，查看下方检修格。 | 点座椅拿走星图仪，它是读舷窗信标用的。 |
| useStarchart | 导航终端让你去舷窗定位信标。 | 选中星图仪，再点舷窗。 | 点星图仪选中再点舷窗，叠加层圈出三颗信标星，按亮度由高到低读数字。 |
| toolbox | 工具箱里应该还有能用的东西。 | 点工具箱，看看里面。 | 点工具箱拿走保险丝，箱盖内侧的维护日志写着信标星读取顺序。 |
| useFuse | 生命维持面板没电，读数区是黑的。 | 选中保险丝，再点生命维持面板。 | 点保险丝选中再点生命维持面板，供电恢复后会播放船长录音，面板显示生维段 25。 |
| code | 三组授权分别藏在导航定位、生命读数和屏保公式里。 | 坐标 418，生维 25，校验位是前五位之和的个位。 | 4+1+8+2+5=20，个位是 0，在控制台输入 418250。 |
| done | 你已经逃出来了。 | — | — |

提示次数记入统计，不惩罚。第三层给出完整解法后仍可继续游戏，不强制跳过。

## 7. 存档、计时与统计

- `localStorage` 键 `dead-orbit.save`，严格字段白名单校验；坏档保留原文备份并以明确中文提示重开。
- 内容版本变更时旧档不崩：先校验来源版本，再迁移；无法迁移的档保留备份后重开。
- 有效计时用单调时钟 `performance.now()`：暂停、后台、菜单、结算、挂机（>5 分钟无输入）不计入有效时长。
- 首次通关与重玩分账：`firstClearMs` / `replayMs` / `attempts` / `restarts` / `hints` / `failures` 分别记录。
- 自动回放（`?automated=1`）单独记账，不混入真人统计。
- 多标签页：owner 租约防止两页同时计时/写档。

## 8. 双端与无障碍

- 同一页面 `data-layout` 属性切换桌面/手机布局，共享规则与线索；手机竖屏直接可玩。
- 按钮 ≥44px，安全区 `env(safe-area-inset-*)`，横竖切换不破版；桌面支持鼠标 + 键盘。
- 三层提示、输错不锁死；所有声音都有视觉对应物（听障可玩）；减弱动效开关；数字 + 文字双重标识（色觉辅助）；键盘全程可达。
- 零 http(s) 外链、零内嵌图片；只请求本目录 `art/`。音效由 Web Audio 现场合成，不落音频文件。
- 声音只做氛围与反馈，不单独承载解谜信息。

## 9. 音效规则（Web Audio 合成，不落文件）

- 氛围：舱体低频嗡鸣、通风滤波白噪、偶发金属应力声、与警报灯同步的提示音。
- 反馈：热点点击、道具拾取、键盘敲击、输错低沉 buzz、供电上涌 swell、发射轰鸣 + whoosh + 收尾和弦。
- 浏览器自动播放策略：AudioContext 必须由「开始游戏」点击解锁，不能加载即响。
- 静音状态存 localStorage；切后台 suspend、回前台 resume，与计时器同一条 visibilitychange 线。
- 任何声音线索都有视觉对应物；不把密码数字只藏在声音里。

## 10. 验收口径

- 授权码 418250 可由线索唯一推出；每条线索可读、每件道具用途唯一；输错不锁死。
- 逻辑单测、存档往返/坏档拒绝/版本迁移、计时边界全绿。
- 四视口真实输入回放通关，0 JS 错误、0 个 ≥400、无横向溢出；移动端按钮 ≥44px。

- 三层提示、撤销选择、当前局恢复可用；自动回放与手机模拟不等于真人/实体机验收，如实标注未验项。
