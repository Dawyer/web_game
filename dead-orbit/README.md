# 静默轨道 DEAD ORBIT

一款纯前端密室逃脱解谜游戏。深空监测站「渡鸦-7」失联 11 个月，你在逃生舱醒来，六名船员不见踪影。找道具、读线索、推理六位授权码，逃离这艘正坠向恒星的站。

**授权码 418250** 由三条线索唯一推出，无猜测、无倒计时、无死亡。剧情内核是一次善意的囚禁，结局留有船长的私人留言。完整规则与剧情见 [RULES.md](./RULES.md)（唯一规则来源）。

## 运行

无需 npm、无构建步骤。在仓库根目录启动静态服务：

    python3 -m http.server 8000 --bind 127.0.0.1

浏览器打开 `http://127.0.0.1:8000/dead-orbit/`。

- 电脑：`?layout=desktop` 强制桌面布局
- 手机：`?layout=mobile` 强制手机布局（竖屏默认自动切手机布局）
- 自动回放：`?automated=1`（供测试用，统计单独记账）

## 玩法

1. 点击场景中的物体查看线索：储物柜、座椅、工具箱、导航终端、舷窗、生命维持面板、控制台、舱门。
2. 详情面板出现「拾取」按钮时点击拾取道具；道具进入物品栏。
3. 点物品栏道具选中，再点场景目标使用；再点一次道具取消选择。
4. 线索自动存入「线索簿」，随时点顶部按钮回看。
5. 推理出六位授权码，在控制台数字键盘输入并确认。
6. 卡住点「提示」，按当前进度给三层提示，不惩罚。

**键盘**：数字键输入、Enter 确认、Backspace 退格、Esc 返回/取消选择、H 提示、J 线索簿、M 静音。

## 存档、计时与统计

- 存档在 `localStorage`（键 `dead-orbit.save`），严格字段校验；坏档保留原文备份并明确提示重开；内容版本变更时旧档迁移。
- 有效计时用单调时钟：暂停、后台、菜单、结算、挂机（>5 分钟无输入）不计入。首次通关与重玩分账。
- 设置里可导出/导入存档、切换静音与减弱动效、查看统计、重置当前局。
- 多标签页用 owner 租约防止重复计时与写档。
