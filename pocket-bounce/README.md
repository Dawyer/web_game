# Pocket Bounce《弹球入袋》

原创单机网格谜题候选版，继续已有项目，不是新开游戏。无账号、付费、广告、道具或联网排行。

## 运行与入口
在本目录执行 `python3 -m http.server 8000 --bind 127.0.0.1`，打开 `http://127.0.0.1:8000/`。
- 自动布局：`/`
- 电脑版：`/?layout=desktop`
- 手机版：`/?layout=mobile`
- 开发自动测试必须加 `&automated=1`（自动布局用 `?automated=1`），计时记入独立账本。

无需安装依赖或构建；原图、音效、脚本均来自本目录。若在仓库根启动服务，路径加 `/pocket-bounce/`。

## 玩法
规则细节和手写预期见 RULES.md。点击静止球沿箭头发出六拍冲量，同色入袋、墙/木箱/异色袋反向、撞球传余拍、镜面转直角。清空即胜，限步用尽可撤销或重试。

鼠标/触屏直接点球；方向键选球、Enter/空格击出、Z 撤销、R 重试、Esc 暂停。下方/侧栏也有全部操作按钮。设置支持声音、减弱动效、A–F 辅助辨色和显式双端切换。

## 存档与计时
仅当前浏览器 localStorage；无跨设备同步。当前稳定棋盘与完整撤销历史在逻辑完成时先保存，动画不改变规则。刷新/切后台后需明确继续。坏档/旧档保留原文备份，导入先校验再确认；清浏览器数据前请导出 JSON。

有效时间只计可交互棋盘内的操作/观察/思考。动画、暂停、后台、菜单、结算、超过五分钟无输入后的疑似挂机单列；恢复须主动继续。重玩与首次主线分开，自动测试与真人分开。JSON 为完整账本，CSV 可供人工检查。

## 检验
HW 显式使用已验证的 Node，不依赖 runner 中继承的 LOS 默认路径：

    NODE=/root/.local/bin/node python3 tools/run_tests.py
    /root/.local/bin/node --max-old-space-size=192 tools/validate_levels.js

测试逐文件串行、192MB heap、单文件超时。关卡搜索逐关串行，状态和时间都有上限；超时不报通过。tools/reference.mjs 不导入引擎，独立 BFS 核对最短与路径上的所有可用动作。原始输出在 evidence/。DOM fixture 不是浏览器，不证明 CSS/真实触摸/音频解码通过。
