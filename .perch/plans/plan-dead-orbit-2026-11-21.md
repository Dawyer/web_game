## 一、游戏设计（已锁定）

**设定**：深空监测站「渡鸦-7」，六名船员，信号断了 11 个月。你在逃生舱座椅上醒来，后脑发疼，广播循环："轨道衰减，脱离窗口关闭中。" 门锁着，中控屏一行字：**发射码校验失败，需三组授权。**

**剧情内核**：生命体征读数显示船员是被"送进休眠"而非撤离；星图显示空间站正朝最近恒星坠落；电路恢复后船长林的录音揭示——他把船员送进休眠、切断通讯、把站导向恒星，是为了烧掉一个跟着信号上船的东西。你是唯一未被感染的，锁住你的安全协议是他最后一道保护命令。结局：三组授权码输入，舱门弹开，渡鸦-7 在身后烧成一道光，屏幕留下船长的私人留言。

**目标**：搜舱室找道具 → 修复/激活设备 → 读出线索 → 推理 6 位授权码 → 输入控制台 → 弹射逃生。

**核心循环**：固定视角点击场景热点 → 拾取道具 → 选中道具再点目标使用 → 设备亮起显示线索 → 综合推理 → 数字键盘输入 → 逃脱。

### 道具（3 件，各有唯一用途，无摆设）
1. **应急电池** — 藏在储物柜，给导航终端供电。
2. **星图仪** — 藏在座椅下，在舷窗定位信标星。
3. **保险丝** — 藏在工具箱，修复生命维持面板。

### 谜题链（6 位码 = 3 位坐标 + 2 位生维 + 1 位校验）
- **D1–D3 轨道坐标**：导航终端（装电池后开机）提示「用星图仪对准舷窗信标」。舷窗叠加层显示三颗圈出的信标星及数字；维护日志写明「按星等由亮到暗读取」→ 4、1、8 → **418**。
- **D4–D5 生命维持**：面板（换保险丝后亮起）显示 O₂ 26%、舱压 5 kPa；贴纸「取氧气十位与舱压个位」→ **25**。
- **D6 校验位**：屏保写「校验位 = 前五位之和的个位」。4+1+8+2+5=20 → **0**。
- **授权码 = 418250**。线索确定可读，无猜测成分；校验位是「啊哈」时刻。

### 难度与容错
- 无倒计时、无死亡。输错只提示「授权失败，请核对」，不锁死。
- 三层提示：① 思路 → ② 下一步 → ③ 完整解法。提示次数记入统计，不惩罚。

## 三、技术方案

沿用 `pocket-bounce` 的模块化骨架，无构建步骤、无游戏引擎，本地静态服务即可运行：
- DOM + SVG 渲染（非 canvas）：热点是真实可点元素，文字清晰，手机原生 touch 命中，44px 按钮好做。
- 零 http(s) 外链、零内嵌图片；只请求本目录 `art/`。音效由 Web Audio 现场合成，不落文件。
- 同一页面 `data-layout` 属性切换桌面/手机布局，共享规则与关卡；手机竖屏直接可玩。
- 存档、有效计时、首次通关与重玩分账，参照 `pocket-bounce/src/persistence.mjs`、`timing.mjs` 的严格校验与单调时钟方案。

## 四、公开上线需完善的 5 个方面

> 这是本次新增的重点。目标是「陌生人点进网站就能玩完并愿意分享」，不只是内部验收通过。

**1. 首屏 30 秒可上手（零说明开局）**
- 开场直接给目标（中控屏「需三组授权」），第一个可交互热点有呼吸高亮引导。
- 内置 3 步交互教学：点热点 → 拾取 → 使用；不读 README 也能开始。
- 验收：找 3 个没看过说明的人盲测，都能在 2 分钟内找到第一件道具并理解目标。

**2. 双端真机可玩（不是模拟器）**
- 竖屏直接可玩、按钮 ≥44px、安全区 `env(safe-area-inset-*)`、横竖切换不破版；桌面鼠标 + 键盘（数字键/Enter/Esc/H）。
- 验收：1280×720 与 375×760 各一张截图；至少一台实体手机真机试玩，不用横屏提示或缩小桌面画面替代适配。

**3. 存档续玩与版本回退**
- 刷新/关闭页面后能续玩；localStorage 严格校验、坏档保留原文备份、版本迁移。
- 内容版本变更时旧档不崩；有明确的版本定位与回退路径（对应看板通用标准）。
- 验收：刷新续玩、坏档拒绝、旧档迁移三组测试全绿。

**4. 加载性能与稳定性**
- 首屏加载快（纯本地静态资源）、0 个 404、0 console 报错；资源加载失败有明确重试提示，不白屏。
- SVG 矢量场景不依赖外部字体或 CDN。
- 验收：四视口回放 0 JS 错误 / 0 个 ≥400；断网模拟下失败提示可读。

**5. 无障碍与零死局**
- 三层提示、输错不锁死；任何声音线索都有视觉对应物（听障可玩）；减弱动效开关；数字+符号双重标识（色觉辅助）；键盘全程可达。
- 验收：关声音完整通关一次；开减弱动效后无异常；Tab 可走通全部功能。

**可选增强（不列入 5 项，先不做）**：结算页提供「复制一句战绩文案」（如「我用 X 步逃出渡鸦-7」）便于分享传播。要加再说。
