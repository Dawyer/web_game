# 密室逃脱《静默轨道》DEAD ORBIT 实施计划

## 一、游戏设计（已锁定）

**设定**：你在「静默轨道」空间站的逃生舱前庭醒来。通讯全断，应急灯低频闪烁，舷窗外是沉默的星海。逃生舱发射控制台需要一组 6 位授权码。站载 AI 只循环一句提示：「发射授权码 = 轨道坐标 + 生命维持 + 校验位」。

**目标**：搜舱室找道具 → 修复/激活设备 → 读出线索 → 推理 6 位授权码 → 输入控制台 → 弹射逃生。

**核心循环**：固定视角点击场景热点 → 拾取道具 → 选中道具再点目标使用 → 设备亮起显示线索 → 综合推理 → 数字键盘输入 → 逃脱。

### 道具（3 件，各有唯一用途，无摆设）
1. **应急电池** — 藏在储物柜，给导航终端供电。
2. **星图仪** — 藏在座椅下，在舷窗定位信标星。
3. **保险丝** — 藏在工具箱，修复生命维持面板。

### 谜题链（6 位码 = 3 位坐标 + 2 位生维 + 1 位校验）
- **D1–D3 轨道坐标**：导航终端（装电池后开机）提示「用星图仪对准舷窗信标」。在舷窗使用星图仪，叠加层显示三颗被圈出的信标星，每颗旁标数字；维护日志写明「按星等由亮到暗读取」→ 例如 4、1、8 → **418**。
- **D4–D5 生命维持**：生命维持面板（换保险丝后亮起）显示 O₂ 浓度 26%、舱压 5 kPa；面板贴纸「取氧气十位与舱压个位」→ **25**。
- **D6 校验位**：控制台屏保写「校验位 = 前五位之和的个位」。4+1+8+2+5=20 → 个位 **0**。
- **授权码 = 418250**。所有线索确定可读，无猜测成分；校验位是「啊哈」时刻。

### 难度与容错
- 无倒计时、无死亡。授权码输错只提示「授权失败，请核对」，不锁死。
- 三层提示：① 思路（「舷窗那边好像能看点东西」）→ ② 下一步（「试试用星图仪对准舷窗」）→ ③ 完整解法。提示次数记入统计，不惩罚。

### 交互与双端
- 点击热点查看；点道具再点目标使用（比拖拽对手机友好）；控制台数字键盘输入。
- 桌面鼠标 + 键盘（数字键输入、Enter 确认、Esc 返回、H 提示）；手机竖屏直接可玩，按钮 ≥44px，安全区 `env(safe-area-inset-*)` 适配。同一页面 `data-layout` 属性切换布局，共享规则与关卡。

### 画面与音效
- 单一舱室固定视角：冷白灰舱体 + 舷窗星海 + 橙色警报灯，电影感。SVG/CSS 矢量绘制，自包含、零内嵌图片、零外链。
- 动效克制：电池插入亮屏、星图叠加浮现、面板亮起、发射倒计时。
- 轻量 Web Audio 合成音效（点击、开锁、成功），不引入音频文件。

## 二、技术方案

沿用 `pocket-bounce` 的模块化骨架，无构建步骤，本地静态服务即可运行：
- `index.html` 骨架 DOM + 本地 `style.css` + `<script type="module" src="./src/app.mjs">`。
- `src/engine.mjs` 纯规则（道具拾取/使用、线索解锁、密码校验），不碰 DOM。
- `src/controller.mjs` 无 DOM 的局状态机（拾取、使用、输入、撤销选择、提示、结算）。
- `src/levels.mjs` 房间数据 + 内容版本；`src/persistence.mjs` 严格校验存档 + 迁移 + 坏档备份 + 导入导出。
- `src/timing.mjs` 有效计时分账（暂停/后台/挂机不计，首次通关与重玩分开）。
- `src/view.mjs` 布局判定 + 热点命中 + 渲染动画；`src/loader.mjs` 本地资源白名单校验。
- `src/app.mjs` 启动接线、Pointer Events 统一输入、键盘、生命周期事件。
